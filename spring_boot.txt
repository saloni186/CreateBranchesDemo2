1. What are the benefits of using Spring Boot?

Answer:
Spring Boot reduces configuration and boilerplate code. It provides auto-configuration, embedded servers (Tomcat), and easy dependency management. It helps build production-ready REST APIs faster with built-in support for security, JPA, and monitoring.

2. How does Spring Security work? How do you implement authentication and authorization?

Answer:
Spring Security works using filters that intercept requests. Authentication verifies the user, and authorization checks user roles/permissions. I have implemented JWT-based authentication using a custom filter.

3. What is Hibernate ORM and why do you use it?

Answer:
Hibernate is an ORM tool that maps Java objects to database tables. It reduces manual SQL, supports CRUD operations, caching, lazy loading, and improves productivity. It also helps write database-independent code.

4. Difference between Spring MVC and Spring Boot?

Answer:
Spring MVC is a framework for building web applications. Spring Boot is built on top of Spring and simplifies configuration by providing auto-configuration, embedded servers, and opinionated defaults.

5. How do you handle transactions in Spring?

Answer:
I use declarative transaction management with @Transactional. Spring automatically commits the transaction if the method succeeds and rolls it back if an exception occurs.

6. What is REST and RESTful API?

Answer:
REST is an architectural style that uses HTTP methods like GET, POST, PUT, DELETE. RESTful APIs are stateless, use JSON, and follow proper HTTP status codes.

7. What is JWT and why is it used?

Answer:
JWT is a token-based authentication mechanism. It is stateless, secure, and suitable for microservices. It avoids server-side sessions and improves scalability.

8. Difference between @Component, @Service, and @Repository?

Answer:
All are Spring stereotypes.

@Component – generic

@Service – business logic

@Repository – DAO layer, also handles DB exceptions

9. What is lazy loading in Hibernate?

Answer:
Lazy loading means related data is loaded only when it is accessed, improving performance and reducing unnecessary database queries.

10. How do you handle exceptions in Spring Boot?

Answer:
I use @ControllerAdvice with @ExceptionHandler to handle global exceptions and return meaningful error responses.

Difference between HashMap and ConcurrentHashMap?

Answer:
HashMap is not thread-safe and allows one null key. ConcurrentHashMap is thread-safe and allows concurrent read/write operations without locking the entire map.

2. What is Java Stream API?

Answer:
Stream API allows processing collections in a functional style using operations like filter, map, and reduce. It improves code readability and supports parallel execution.

3. Difference between == and .equals()?

Answer:
== compares object references, while .equals() compares object values.

4. What is immutability? Why is String immutable?

Answer:
Immutable objects cannot be changed after creation. String is immutable for security, caching, and thread safety.

5. What is Optional in Java?

Answer:
Optional is a container object used to avoid NullPointerException by explicitly handling null values.

🔥 Hibernate / JPA
14. What is the N+1 problem?

Answer:
It occurs when Hibernate executes one query to fetch parent records and N additional queries for child records. It can be solved using fetch joins.

15. Difference between Lazy and Eager fetching?

Answer:
Lazy loads data only when needed. Eager loads data immediately.

16. What is @Transactional?

Answer:

17. Difference between save() and saveAndFlush()?

Answer:
save() persists data later, while saveAndFlush() immediately writes to the database.
