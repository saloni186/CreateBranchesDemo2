service registary and descovery :-
----------------------------------service registary is the centralized registery of all micro services.it collect inforamation of all the microservices  and maintan .
-> we have to add urecka server dependency
-> enable Euereka server in spring boot main application @EnableEurekaSevice
-> you must defone port number as server.port=8761
-> once service registary started it will always started with default UI PORTAL
-> fo implementing service registary we have Eureka claint provided by netflix.
-> by default service registary register itself an discovery client, in this case we have to stop this defualt behavior
-> by default our micro services not regiater with Eureka servcer
-> to make our micro services as discoverable client for service registery we have to add dependency Eureka client(Eureka discovery client) provided by netflix. as well as we have to enable a annotation on each micro service level (@EnableDicoveryClient)
-> we have to add service registary url in our micro services(eureka.client.service-url.defaultZone=http://localhost:8761/eureka
)
