What is JIRA?

Answer:
JIRA is a project management and issue-tracking tool developed by Atlassian.
It is mainly used to track tasks, bugs, and development work in software projects.

Teams use JIRA to plan, track, and manage work throughout the software development lifecycle.

Why Do We Use JIRA?

We use JIRA to:

Track tasks, bugs, and user stories

Plan work using Agile (Scrum / Kanban)

Assign work to team members

Track progress and deadlines

Maintain transparency between dev, QA, and managers

Real-World Example

In a real project:

Product owner creates user stories

Developers work on assigned tasks

QA raises bugs

Status is updated (To Do → In Progress → Done)

All this is tracked in JIRA.

Key Concepts in JIRA (Interview Important)

Issue – A task, bug, or story

Story – Feature requirement

Bug – Defect in the application

Epic – Large feature

Sprint – Fixed time development cycle

Backlog – List of pending work

Workflow – Issue status flow

How Developers Use JIRA

“As a developer, I use JIRA to pick up assigned stories, update task status, log work, and track bugs.”

One-Line Answer (Most Important)

“JIRA is an issue-tracking and project management tool used to manage and track software development work.”
