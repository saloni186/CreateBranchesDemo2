1)ab*:- a followed by zero or more accurence of b. EX :-a ab abbb abb...
2)ab+:- a followed by one or more occurence of b. Ex:-ab abb abbb...
3)ab?:-a followed by zero or one occurence.Ex:-a ab
4)ab{n}:-n times of preciding character,a followed by  times of b. Ex:-ab{2}=abb,ab{1}=ab
5)ab{m,n}:-ab{3,4}->abbb abbbb(min limit=3,max limit=4)
6)ab{m,}:-ab{3,}->abbb abbbb abbbbb..
7)ab.:-apbr(a and b ke bech me nya single line character aa skta hai)
8)match any character--DOT-a.b:-acb a&b ()[a and b ke bich me koi sa bhi charater likh skte hai]
9)one or more--plus :- a aa aaa
10)zero or one-? ab?c abc ac
11)zero or more--star :-ab*c->ac abc abbc abbbc
12)interval--exact count ->a{5} aaaaa
13)interval--atleast count ->a{3,}  aaa aaaa aaaaa..(atleast 3 times)
14)interval--between count ->a{3,4} aaa aaaa 
15)matching character list :-[abc][a-b][a-z]->seaech a z any character ->at bet cet
16)not matching character list :-[^abc][^a-i]:-abc ko chhor ke sab chlega abcgef gif, abcdefghi nhi chlega

8. what is trigger ?
ans :-A trigger is a special type of stored program that autometically executes when a specific event occure on the table like :insert ,update ,delete.

query:-
CREATE OR REPLACE TRIGGER after_ouremployees_insert
AFTER INSERT
ON ouremployees
FOR EACH ROW
BEGIN
    INSERT INTO employee_logs(emp_id, action_type, action_time)
    VALUES (:NEW.emp_id, 'INSERT', SYSDATE);
END;
/

2)AutomateProcesses

what is the difference between where and having cluase ?
where :-it is used to filter row before grouping.it cannot use aggrigate function.
having :-it is used to filter rows after grouping and it can use aggrigate function.
Ex:- select department_id.couunt(*)
     from employees 
     where salary>3000 
     groupBy department_id 
     having count(*)>5 
     order by department_id;

WHERE vs HAVING — Samajh le bhai!
Feature	           WHERE	             HAVING
Kab use hota?	GROUP BY se pehle	GROUP BY ke baad
Kis pe kaam karta hai?	Rows	Groups
Aggregate function chalta?	❌ Nahi	✅ Haan
Example	WHERE salary > 50000	HAVING AVG(salary) > 45000

what is indexing in sql?
ans :-with the help of indexing we can fatch the data from detabase fastly,instead of scaning entire table row one by one, indexing allw us to jump relavent row directly, it will hepl us to improve the performance and reduce execution time.

there are two types of indexing :-
1)single column index :- when we apply indexing on one column.
	create index index_name on table_name(column_name)

2)composite indexing :-when indexing based on multiple columns.
	create index index_name on table_name(colum1,column2)

3)unique index :- it prevents duplicate values in the index column.
	create unique index index_name on table_name(column_name) 

where we should not use indexing :-
1) on small tables,
2) when table columns does not hold more duplicate data.

ex :-CREATE TABLE Employees (
    EmployeeID INT,
    Name VARCHAR(100),
    DepartmentID INT
);

-- Create an index on DepartmentID
CREATE INDEX idx_dept ON Employees(DepartmentID);
