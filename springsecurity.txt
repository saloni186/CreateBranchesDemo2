-------------------------- of our application.

but in realty we need  to secure only few methods not all methods in our application :-

					contect us=no security
					login     =security
in order to achive above requirment we need to costomized security configuration in out project.

@Bean
	public SecurityFilterChain getSecurity(HttpSecurity http) throws Exception {

		http.authorizeHttpRequests(req -> req.requestMatchers("/contect").permitAll().anyRequest().authenticated())
				.httpBasic(Customizer.withDefaults()).formLogin(Customizer.withDefaults());

		return http.build();
	}

JWT token has three parts :
----------------------------

1)header :-which type of token we are using and what algorithum we are using 
2)payload :- it holds user inforamtion, which user use this token
3) signature:-secrete  key is available for this token(encoded header+encoded body+secret key)
all three parts are diveded by (.)

OncePerRequestFilter(AppFilter class) class:-
----------------------- this class is responsible for validate the token.if the token is valide then request will be proccess if token is invaide then proccess will be failed.
-> this class executes when the request come for secured URL patterns
->checks token present for request.
-> if token is available then read the token and validated the token and proccess the request
-> if token is not available then then sent roor msg .does not proccess the request.
