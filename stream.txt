Stream operations :-
-------------------
stream pipeline :-

1. Intermidiate operatons :-when we call method belongs to intermidiate operations.it always return another stream instanse as result , we can call many intermidiate operation on same stream instance as chain of method that is called stream pipeline.
intermidiat operation executes only once when we invoke  terminate operation.

Terminal operations :-
--------------------

1. we can call only one terminal method on any stream instance
2.when we call terminal method , we will get the result of all pipeline operationed which are performed on stream instance.

peek():- for tracing or perform any action, what are the values being proccessed from one operation to another operation,Debugging & logging

stream():- the stream object is created in sequesncial stream, the elements inside stream will be proccessed one by one in stream,thats why is will take more time to perform opreations.it will give the guarantee of proccessing of elements 
parallel stream() :-the stream object is created in parallul stream, when we create parallel stream objects the stream is devided into multiple segments and each and every segment is proccess by each any every therad symolutaniously work on steam elements. it will take less time to perform operations , it will not guarantee of order of proccesssing of elements

what is difference between map() and flatMap();
Ans :-In Streams, map() is used for one-to-one mapping—each element is transformed into another single element.
flatMap() is used for one-to-many or many-to-many mapping—when each element returns a stream or collection, and we need to flatten those into a single stream.”
