------------ headers are used to share mata data between client and server.
	     it share additional imforamtion as part of request and response.
		Ex: with bussiness logic send content type  either JSON or XML(along with request) etc.
it segrigate into two parts
1) Request header:- header which is part of request
			Ex:content-type    :     application/json,application/xml(data type of Request body sent by client to server)
			content-type       :     response accepted by client
			Accept 		   :     is header represent what type of response it will accept(*/* both xml and json)
						if accept=application/json then client only accept json,and if accept= application/xml then client only accept xml
					
2)response header   : the header or extra imformation which is receiving  from server side to client side is called as Response header.



again ther are two types of headers :-

1)pre-defined headers :-which is pre defined by Http protocol

@PostMapping("/get/authonticaton")
	public ResponseEntity<UserInfomation> getAuthenticateUser(@RequestBody UserInfomation userInfomation) {

		boolean isvalide = true;

		if (isvalide) {

			UserInfomation body = new UserInfomation("suhana", "suhana@gmail.com", "shuhana123");
			HttpHeaders header = new org.springframework.http.HttpHeaders();
			header.add("security-token", UUID.randomUUID().toString());
			header.add("accept", "*/*");

			ResponseEntity<UserInfomation> responseEntity = new ResponseEntity<UserInfomation>(body, header,
					HttpStatusCode.valueOf(200));
			return responseEntity;
		} else {
			return ResponseEntity.ok(null);
		}
